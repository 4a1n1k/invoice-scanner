## ✅ טופלו

### [B-001] TypeScript parse error ב-upload/page.tsx
- **סיווג:** בינוני
- **תאריך:** 2026-03-27
- **סטטוס:** ✅ סגור
- **Root Cause:** `return (` פתח בלי `<div>` עוטף ב-`TimingBadge` JSX — נגרם מעריכה חלקית של הפונקציה
- **תיקון:** הוספת `<div className="flex items-center gap-3 ...">` מיד אחרי `return (`
- **חזרות:** 0

### [B-002] TypeScript error — ParsedInvoice cast ב-/api/v1/receipt
- **סיווג:** נמוך
- **תאריך:** 2026-03-25
- **סטטוס:** ✅ סגור
- **Root Cause:** `result as Record<string, unknown>` — TypeScript לא מאפשר cast ישיר כי אין index signature ב-ParsedInvoice
- **תיקון:** `result as unknown as Record<string, unknown>` — double cast מקובל
- **חזרות:** 3 (אותה שגיאה בשלושה מקומות שונים)

### [B-003] חשבוניות הפוכות לא מזוהות — שופרסל + MAX stock
- **סיווג:** בינוני
- **תאריך:** 2026-03-27
- **סטטוס:** ✅ סגור
- **Root Cause:** `sharp.rotate()` מתקן EXIF בלבד. צילום ידני הפוך (180°) לא מתוקן
- **תיקון:** `detectUpsideDown()` — השוואת בהירות 12% עליון vs תחתון, סיבוב 180° אם נדרש
- **חזרות:** 0

### [B-004] ווטרמארק מבלבל OCR — רמי לוי, סופר-פארם
- **סיווג:** בינוני
- **תאריך:** 2026-03-27
- **סטטוס:** ✅ סגור
- **Root Cause:** Tesseract מחזיר את שם הרשת מהווטרמארק כשורה בטקסט, ה-LLM בוחר אותו כשם העסק
- **תיקון:** 1) הוספת watermark patterns ל-NOISE_PATTERNS, 2) הוראה מפורשת בprompt להתעלם מווטרמארק
- **חזרות:** 0

### [B-005] שילב SMS — קישור פרטיות נבחר במקום קישור חשבונית
- **סיווג:** בינוני
- **תאריך:** 2026-03-25
- **סטטוס:** ✅ סגור
- **Root Cause:** Pass 1 לא זיהה "לצפייה" לפני URL כי המרחק היה >40 chars
- **תיקון:** Pass 0 — בדיקת path של URL עצמו: `/r/` = receipt, `/l/` = privacy
- **חזרות:** 0
